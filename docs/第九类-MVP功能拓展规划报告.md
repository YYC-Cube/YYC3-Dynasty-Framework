## 三、技术实现路径

### F1: WebSocket 实时推送

```
现状: HTTP 5s 轮询（countdown 倒计时）
方案: 
  1. 后端 WebSocket 端点已存在 (`/ws`) → 增强事件订阅
  2. 前端 `useWebSocket` hook → 替代 `setInterval` 轮询
  3. 降级策略: WebSocket 断开时自动回退到 HTTP 轮询

架构:
  前端 useWebSocket hook
      ↓ 连接 /ws
  后端 WebSocket endpoint
      ↓ 订阅 Pub/Sub
  Redis EventBus → Publish → Pub/Sub Channel
```

### F2: 朝堂议政 UI 重构

```
现状: ~700 行内联 Tailwind 类，与全项目 CSS 类风格割裂
方案:
  1. 提取所有内联样式为 CSS 类 → `index.css` 追加 `.court-*` 命名空间
  2. 响应式适配: 朝堂布局在大屏显示朝堂座位图 → 小屏折叠为消息列表
  3. 动画优化: 发言者高亮 + 打字机效果
```

## 四、功能规格文档

### F4: 圣旨模板市场 — 详细规格

#### 4.1 功能描述

建立社区共享的圣旨模板市场，用户可以从官方/社区模板源一键下载并使用旨意模板，也可以提交自己的模板。

#### 4.2 用户场景

| 场景 | 用户 | 流程 |
|------|------|------|
| 浏览模板市场 | 皇帝/官员 | 打开"旨库"Tab → 切换到"市场" → 浏览分类 |
| 下载模板 | 皇帝/官员 | 点击"安装" → 模板下载到本地 → 可在旨库中使用 |
| 提交模板 | 开发者 | 提交 PR 到官方模板仓库 → 审核后上架 |

#### 4.3 数据结构

```typescript
interface MarketplaceTemplate {
  id: string;
  name: string;
  icon: string;
  cat: string;
  desc: string;
  author: string;
  version: string;
  stars: number;
  installs: number;
  source_url: string;
  depts: string[];
  params: TemplateParam[];
  command: string;
}
```

#### 4.4 UI 设计规范

```
旨库 Tab
├── 本地旨库（现有）
│   └── TemplatePanel 不变
└── 模板市场（新增）
    ├── 分类筛选栏
    ├── 搜索框
    ├── 模板卡片网格
    │   ├── 图标 + 名称
    │   ├── 作者 + ⭐ 评分
    │   ├── 描述（2行截断）
    │   └── "安装"按钮
    └── 已安装标签
```

### F5: 功绩排行榜 — 详细规格

#### 5.1 功能描述

在官员总览页面新增可视化功绩排行榜，展示各部官员的 Token 消耗、任务完成数、功绩分数等 KPI 对比。
