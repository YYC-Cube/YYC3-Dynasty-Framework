## 1. 设计语言统一

### ✅ 1.1 颜色系统

**现状评估：基本统一，存在一些差异**

| 项目 | 状态 | 说明 |
|------|------|------|
| CSS 变量体系 | ✅ | 统一使用 `:root` CSS 变量 (`--bg`, `--panel`, `--text`, `--acc` 等)，所有组件引用一致 |
| Tailwind 主题色 | ⚠️ 未使用 | `tailwind.config.js` 定义了 `imperial` 和 `dynasty` 色系，但未被任何组件引用 |
| 部门颜色 | ⚠️ 双重定义 | `DEPT_COLOR` 在 store.ts 中定义，又在 index.css 用 `.dt-*` 类重复定义 |
| 状态颜色 | ⚠️ 双重定义 | `STATE_LABEL` 在 store.ts，`.st-*` 类在 index.css |
| 内联颜色值 | ⚠️ 散落 | CourtDiscussion.tsx 中 `OFFICIAL_COLORS` 与 store.ts 中 `DEPT_COLOR` 值重复定义 |
| 颜色透明度 | ⚠️ 不一致 | 有的用 `44` 后缀 (`#6a9eff44`)，有的用 CSS `rgba()` |

**问题详情：**

1. **Tailwind 主题色未使用** — `tailwind.config.js` 定义了 `imperial` 和 `dynasty` 色系但零引用。如果要去 Tailwind 化则删除；如果要用 Tailwind 则应全面迁移。
2. **颜色定义分散在三处**（store.ts DEPT_COLOR / index.css .dt-* 类 / CourtDiscussion.tsx OFFICIAL_COLORS），修改需维护三处。
3. **CourtDiscussion.tsx** 使用 tailwind 类如 `bg-[var(--panel)]` 混合方式，其他组件统一用 CSS 类，渲染方式不一致。

**改进建议：**

- 将颜色定义统一到 `index.css` 或一个 `colors.ts` 常量文件
- 组件中的 `OFFICIAL_COLORS` 引用 store.ts 中的 `DEPT_COLOR`
- 内联 `style={{ color: ... }}` 应统一为 CSS 变量或类名
- 删除未使用的 Tailwind 主题色或全面启用

**无问题。** 命名规范统一度非常高。

### ⚠️ 2.2 代码格式

| 问题 | 严重度 | 说明 |
|------|--------|------|
| 内联样式 vs CSS 类 | 高 | 大量组件混用 `style={{}}` 和 CSS 类。CourtDiscussion 最严重，几乎全内联 |
| 字符串引号不统一 | 低 | 大部分用单引号 `'`，部分用双引号 `"` |
| 箭头函数 vs function | 中 | 组件函数定义不一致：`export default function X` (大部分) vs `const X = () =>` |
| React memo 缺失 | 低 | 无 `React.memo` 使用，列表渲染可能有性能优化空间 |

**示例对比 — 同样功能的按钮用不同风格：**

风格A（CSS 类）：

```tsx
<button className="btn-action btn-stop">⏸ 叫停任务</button>
```

风格B（内联样式）：

```tsx
<button style={{ background: '#2ecc8a22', color: '#2ecc8a', border: '1px solid #2ecc8a44' }}>
  ✅ 准奏
</button>
```
