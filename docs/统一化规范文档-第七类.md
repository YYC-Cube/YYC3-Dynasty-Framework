## 2. 代码规范

### 2.1 命名规范

| 场景 | 规范 | 示例 |
|------|------|------|
| React 组件 | PascalCase | `EdictBoard`, `TaskModal` |
| 普通函数/变量 | camelCase | `getPipeStatus`, `loadAll` |
| 常量 | UPPER_SNAKE_CASE | `PIPE`, `DEPT_COLOR` |
| CSS 类名 | kebab-case | `edict-card`, `ep-node` |
| Python 函数 | snake_case | `get_settings`, `load_live` |
| 文件命名（TS） | PascalCase + `.tsx` | `EdictBoard.tsx` |
| 文件命名（Python）| snake_case | `event_bus.py` |

### 2.2 格式规则

- **字符串**：统一使用单引号 `'`
- **缩进**：2 空格（TS/TSX），4 空格（Python）
- **组件定义**：统一使用 `export default function ComponentName`，避免 `const Component = () =>` 风格
- **样式**：优先使用 CSS 类，避免内联 `style={{}}`。CSS 类命名遵循 kebab-case
- **分号**：统一使用分号（TS/TSX）

### 2.3 注释规范

```typescript
// ── 节标题 ──（居中 20 字符宽度）

/** JSDoc 风格：组件/函数描述 */
export default function Component() {}

// 普通注释：描述性说明

// TODO: 待办标记
// FIXME: 需修复的问题
```

### 2.4 导入规范

```typescript
// 1. 第三方依赖
```

## 4. 交互规范

### 4.1 弹窗行为

| 行为 | 规范 |
|------|------|
| 打开 | 渐入（opacity transition 0.15s）|
| 关闭 | 点击背景关闭 / 点击 ✕ 按钮 |
| 层级 | `z-index: 100` |
| 背景 | `rgba(0,0,0,.7)` + `backdrop-filter: blur(3px)` |
| 尺寸 | `max-width: 760px`，居中显示 |

### 4.2 加载状态

| 状态 | 显示内容 |
|------|---------|
| 初始加载 | `⟳ 加载中…`（使用 CSS 类而非内联）|
| 空数据 | 使用 `<div className="empty">` |
| 错误 | `toast(msg, 'err')` 统一处理 |
| 刷新 | `⟳` 按钮 + countdown 倒计时 |

### 4.3 表单交互

- 提交前校验必填项
- 提交过程显示 loading 状态
- 成功后 toast 提示并关闭/重置表单
- 失败后 toast 显示错误信息

### 4.4 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Escape` | 关闭当前弹窗 |
| `Ctrl+Enter` | 提交表单 |
